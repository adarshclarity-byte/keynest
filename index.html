Two vaults, one extension.

The main idea: a manager or IT admin saves shared logins that teammates can use, but never see. Everyone still keeps their own personal vault on the same machine, encrypted with their own password.

Personal

User vault

What you would expect from a password manager. Yours to add, view, edit, delete.

  • ● Set by you
  • ● Your password to unlock
  • ● Full read and write access
  • ● Auto-locks after idle
+
Managed

Admin vault

For a parent, IT admin, or team lead. Sites you set once and let the user sign into, without ever showing them the password.

  • ● Set by an admin
  • ● Silent autofill on managed sites
  • ● Admin password to view or edit
  • ● User never sees the secret
A few places it fits
🏢
IT team at a company
Admin drops the company's SaaS logins into the admin vault. Employees sign in every day without ever seeing the password. When someone leaves, wipe the admin vault, done.
👥
Manager sharing with the team
Team lead saves the shared vendor account, the marketing tool, the internal dashboard. Everyone on the team can use them, nobody can copy the password out.
🏠
Family or shared PC
Parent puts Netflix, Prime, and Spotify in the admin vault. Kids sign in through the user vault for their own school stuff. Passwords stay with the parent.

Short answers.

Forgot the master?

No reset. That is the point.

Same password for both?

Not allowed. Setup blocks it.

Does it sync?

No. Export, then import on the other device.

Where does the data sit?

chrome.storage.local, encrypted.

Clear browsing data?

Doesn't touch it. Safe.

Skip the admin vault?

Sure. It's optional at setup.
